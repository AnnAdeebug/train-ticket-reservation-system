# Train Ticket Reservation System

A train ticket reservation system originally developed as a university project in 2022.

This project is being revisited and refactored as part of my personal software development learning journey.

## Original Project

The original version was developed during my university studies using C/C++ concepts.

Features includes:

* User login
* Train information
* Train ticket reservation
* Fare calculation
* Ticket printing
* Reservation cancellation
